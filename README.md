# edu_games

Обучающие браузерные игры для разработчиков. Каждая игра — один HTML-файл: откройте его в браузере, установка не нужна.

| Игра | О чем |
|---|---|
| [mongo-detective.html](mongo-detective.html) | Mongo-детектив: раскройте кражу алмаза из музея, выполняя запросы к MongoDB — от `find` до индексов и агрегаций. |
| [sql-detective.html](sql-detective.html) | SQL-детектив: найдите похитителя картины «Синяя цапля», задавая SQL-запросы полицейской базе данных. |
| [thread-race.html](thread-race.html) | Гонка потоков: побудьте планировщиком и разберитесь с потоками Java, гонками, `synchronized`, дедлоками и виртуальными потоками. |
| [z3-bureau.html](z3-bureau.html) | Z3: Бюро невозможных задач — решайте головоломки, задачи оптимизации и верификации с помощью SMT-решателя Z3. |
| [oncall.html](oncall.html) | Дежурный: симулятор ночных инцидентов в проде — алерты, метрики, логи и фича-флаги, чтобы сохранить error budget. |
| [monolit.html](monolit.html) | Эволюция монолита: раунд за раундом принимайте архитектурные решения, пока система растет под нагрузкой. |
| [java-job-hunt.html](java-job-hunt.html) | Java Job Hunt: пройдите собеседования на Java-разработчика (Java 17–25, Spring Boot, Kafka, PostgreSQL), пока не кончились деньги. |
